# ProcurementEngineV2

The workflow-first procurement solution generated by the Agent Architecture Studio from four business processes,
built on mocks. `docs/architecture.md` is the specification (sections 1–10) and the plan (section 11); this code
implements it. Read `README.md` for the picture and `docs/architecture.md` §11.1 for the working agreement.

## How work happens here

- **The architecture document is the spec.** Components, rules, approvals and schemas are not changed in code;
  they change in the studio, which regenerates the document. Keep the node and step names of the document as
  identifiers (workflow step names, service ids, audit fields) so traceability survives.
- **No real business transaction, ever.** Every integration is a mock in `src/pev2/tools/`. A real adapter is a
  separate, flagged deliverable (phase 5) and is off by default.
- **Rules are tests.** The logic lines under each service in §3 are the unit tests in `tests/services/`. Write the
  test from the rule text first.
- **Approvals are real pauses.** Never auto-approve, not even in demos; tests decide through the runtime API.
- **The unknown case is the investigator's, and it only proposes.** `investigation.py` holds the guardrails (read-only
  allow-list, `investigation_safe` gate, discoveries log). Never give it a write tool; never execute a proposal from code.
  New paths come from the gap report through the studio, not from widening the agent.
- **Agents only through the gateway**, with the tool allow-list, limits and output schema of §2. Untrusted content
  goes to the model inside `<data>` blocks.
- **Knowledge lives in three layers**: hard limits in `tools/limits.py` (enforced by the tool registry, never a
  prompt), arithmetic in tested service functions, everything else in `fixtures/brain/` markdown that the services
  read at run time (change the tolerance in the policy and the matcher behaves differently).

## Tooling

- Python 3.12+, `uv` only. `uv run pytest` offline; `uv run ruff check`; `uv run mypy src/`.
- `uv run pev2 ui` (Gradio on :7860), `uv run pev2 api` (:8000), `uv run pev2 demo`, `uv run pev2 smoke --engine`,
  `uv run pev2 evals run`.
- Money is `Decimal`. The clock is `PEV2_CLOCK` (default in `.env.example`: 2026-10-20) via `config.now()`.
